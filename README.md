# 💻 LeetCode Solutions & DSA Journey

A curated repository of my Data Structures and Algorithms (DSA) solutions. This serves as a log of my problem-solving journey, focusing on writing clean, efficient, and optimal code for coding interviews.

---

## 🗂️ Topic Breakdown

Solutions are organized by core computer science concepts and data structures:

* **Arrays & Strings** — Sliding window, two pointers, prefix sums, and string manipulation.
* **Linked Lists** — Reversals, fast/slow pointers, and pointer manipulation.
* **Stacks & Queues** — Monotonic stacks, parentheses matching, and queue implementations.
* **Trees & BST** — Traversals (DFS/BFS), recursion, and binary search tree operations.
* **Graphs** — Breadth-First Search (BFS), Depth-First Search (DFS), topological sort, and shortest paths.
* **Dynamic Programming** — Memoization, tabulation, and state transition optimization.
* **Recursion & Backtracking** — Subsets, permutations, and constraint satisfaction.
* **Searching & Sorting** — Binary search variations and custom sorting logic.
